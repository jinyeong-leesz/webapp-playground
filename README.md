# webapp-playground

## 장기요양 실무노트

방문요양, 주·야간보호, 요양원 실무자가 자주 찾는 내용을 분류별로 모은 앱입니다. 설치할 것 없이 브라우저만 있으면 됩니다.

- 분류: 요약 / 업무 방법 / 청구 / 용어 / 시스템·사이트 / 법령·매뉴얼
- 업무별 보기: 방문요양 / 주·야간보호 / 요양원 / 공통
- 검색: 제목, 본문, 표 내용까지 찾습니다

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `data.js` | 실무 자료 내용 (여기만 고치면 내용이 바뀝니다) |
| `index.html` | 화면 구조 |
| `style.css` | 색상, 글꼴, 배치 |
| `script.js` | 검색·필터 동작 |

## 내용 추가·수정

`data.js`의 `ITEMS` 목록에 항목을 추가하거나 고칩니다. 맨 위 주석에 항목 형식이 적혀 있습니다.

- 항목을 원문과 대조했으면 그 항목의 `checked`를 그날 날짜로 바꿉니다. 180일이 지나면 앱에 '다시 확인' 표시가 붙습니다.
- 전체를 다시 정리했으면 `UPDATED`(전체 정리일)도 바꿉니다.

## 원문 변경 알림

매주 월요일 오전 9시쯤 GitHub Actions가 `tools/sources.json`에 적힌 공단 고시 페이지를 확인합니다.

- 고시·공고 번호(예: 제2026-189호)가 새로 보이거나 사라지면, 또는 본문 내용이 바뀌면 `원문-변경` 라벨이 붙은 이슈를 만듭니다. 열린 이슈가 있으면 거기에 댓글로 이어서 남깁니다.
- 페이지에 접속하지 못해도 같은 이슈에 "확인하지 못한 원문"으로 남깁니다.
- 처음 실행할 때는 비교 대상이 없어서 현재 상태만 저장합니다(`tools/source-snapshot.json`).
- 바로 확인하려면 저장소 **Actions > 원문 변경 확인 > Run workflow**를 누릅니다.
- 확인할 페이지를 늘리려면 `tools/sources.json`에 추가합니다.

알림은 "바뀐 것 같다"는 신호일 뿐이고, 앱 내용은 자동으로 바뀌지 않습니다. 원문을 읽고 `data.js`를 고친 뒤 이슈를 닫아 주세요.

## 실행 방법

- 내 컴퓨터: 저장소를 내려받은 뒤 `index.html`을 더블클릭하면 브라우저에서 열립니다.
- 인터넷에 공개: 저장소 **Settings > Pages**에서 Branch를 `main`, 폴더를 `/ (root)`로 지정하고 저장합니다. 잠시 뒤 `https://jinyeong-leesz.github.io/webapp-playground/` 주소로 열립니다. (무료 계정에서 Pages를 쓰려면 저장소가 Public이어야 합니다.)
